# 生成考试题

## 任务
根据给定记忆出一套自测题，检验对知识的真实掌握，题目必须全部有据可依。

## 输出格式
- 共出 5~10 题，混合题型：单选、填空、简答（标注题型）；
- 每题末尾标注来源 [id]；
- 全部题目之后放 `## 答案` 一节，逐题给答案与一句话解析；
- 解析里指出该题考查的是材料中的哪个事实。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 每道题的正确答案都能在材料中找到？
- 干扰项是否 plausible 但明确错误（不是脑筋急转弯）？
- 答案节完整覆盖所有题目？
