# llm_skills 编写规范

每个学习动作一个 md 文件（action 名同名；custom 用 `_custom.md`）。统一四段结构：

1. **任务**：一段话说清这个动作要产出什么、给谁看；
2. **输出格式**：结构要求（标题层级、列表形态、必须包含的小节、长度下限）——
   代码侧 `llm_client.validate_output` 会按这里的承诺做结构校验，两边必须对齐；
3. **范围纪律**：三条铁律原文（只用材料 / 标注材料未覆盖 / [id] 引用），一字不改；
4. **自查清单**：模型生成前的自检提示。

加新按钮的步骤：新增 md → `llm_client.ACTIONS` 加名字 → `validate_output`
加校验规则 → console 前端加按钮与 i18n。校验是质量门不是安全门：两试不过
走 degraded 透传（带警告），不吞结果。
