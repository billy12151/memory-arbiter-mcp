# 快速总结

## 任务
把给定记忆压缩成一份要点总结，让读者不读原文也能抓住核心事实。

## 输出格式
- 先用 2~3 句话给出总括；
- 然后按要点列出（无序列表），每条要点末尾用 [id] 标注来源记忆；
- 有明显时间线的结论在末尾单列一行「时间脉络」；
- 全文 ≥100 字符。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 每条要点都能在材料里找到出处？
- 没有为了"完整"而脑补材料没有的背景？
- 总括句与要点之间没有互相矛盾？
