# 知识点梳理

## 任务
把给定记忆整理成结构化知识大纲，按主题层次组织，方便复习与查漏。

## 输出格式
- 用 `## 二级标题` 划分主题块（≥2 个）；
- 每个主题块内用无序列表列出知识点，重要概念用 **加粗**；
- 末尾加 `## 关联与缺口` 一节：指出材料内部互相印证的点、以及材料明显缺一块的地方（标「材料未覆盖」）；
- 引用具体记忆时带 [id] 标记。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 层次是否真的按主题组织（而不是按记忆逐条罗列）？
- 每个知识点都有出处？
- 缺口一节是否诚实（没有硬凑）？
