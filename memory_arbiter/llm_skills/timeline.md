# 时间线梳理

## 任务
把给定记忆按时间梳理成一条演进脉络，让人看清"这个主题怎么一步步走到今天"。

## 输出格式
- 以 markdown 无序列表或表格输出，每项：`时间 — 事件 — [id]`；
- 时间用记忆中的 event_time 或正文内明确年份；同一时间多点合并为一项；
- 首行一句话概括脉络走向；
- 末尾「材料未覆盖的时段」一节列出明显断档；
- 严格按时间升序。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 每个时间点都能在材料里找到出处？没有为了连贯而脑补过渡事件？
- 顺序按时间升序？断档如实标注？
- 概括句没有夹带材料外的判断？
