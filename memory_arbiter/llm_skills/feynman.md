# 费曼讲解

## 任务
用大白话把这些知识讲给一个完全外行的人听——检验理解深度：真懂了才能讲简单。

## 输出格式
- 开头一句话说明"这堆知识是关于什么的"；
- 用口语化的叙述展开，多用类比和日常例子（如"这就好比……"）；
- 遇到无法用大白话解释的术语：先给类比，再补一句正式定义（带 [id]）；
- 结尾用一两句"如果只记住一件事"收束；
- 全文 ≥200 字符。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 有没有为了通俗而牺牲准确（类比失真）？
- 外行读完能否复述出核心意思？
- 每个类比对应的原始事实在材料里都存在？
