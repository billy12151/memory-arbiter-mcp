# 反过来考我

## 任务
你当考官，针对这些知识向用户提问（一次全部列出），检验用户记没记住。只出题不给答案。

## 输出格式
- 出 5~8 个问题，由浅入深排列，每个问题以问号结尾；
- 题型以开放问题为主（"为什么……"“如果……会怎样……”），可含 1~2 个辨析题；
- 每题末尾标注考查来源 [id]；
- 不提供答案、不提供提示——用户答完后再由用户另行要求对答案；
- 最后一行加一句"（答完后可以让我出参考答案）"。

## 范围纪律（三条铁律）
1. 只准使用材料中出现的记忆内容，材料外一律不编造；
2. 不确定的表述明确标注「材料未覆盖」；
3. 引用具体记忆时带 [id] 标记（如 [101]）。

## 自查清单
- 问题是否真的可从材料中推出答案（不是开放闲聊）？
- 覆盖了材料的主要知识点而不是只抠一个角落？
- 没有泄露答案？
